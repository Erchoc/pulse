Pulse API Documentation

REST API v1 — Base URL: /api/v1

v0.1.0
All API requests require the X-API-Key header. You can find your API key in Settings → OpenAPI Integration.

Health

GET /healthz
Health check endpoint. Returns server status.

Services

GET /api/v1/services
List all services with SLA metrics and status.

Probes

GET /api/v1/probes
List all configured probes.
POST /api/v1/probes
Create a new probe.

Push (Client Heartbeat)

POST /api/v1/push/:token
Client-side probe heartbeat endpoint. Push probes send periodic heartbeats to this endpoint.

Maintenance

POST /api/v1/services/:id/maintenance
Start maintenance window for a service. Probe failures won't count toward SLA during maintenance.
{
  "reason": "Database migration",
  "end_at": "2026-04-15T18:00:00Z",
  "notify_users": ["user-1", "user-2"]
}
DELETE /api/v1/services/:id/maintenance
End maintenance window for a service.
GET /api/v1/services/:id/maintenance/history
Get maintenance history for a service.

Settings

GET /api/v1/settings
Get platform settings (project name, retention, SLA window, etc.)

Webhook

POST /api/v1/settings/webhook/test
Test webhook delivery. Sends a test payload to the configured URL.

Example Request

curl -H "X-API-Key: your-api-key" \
     https://your-pulse-instance/api/v1/services

Response Format

{
  "data": [...],
  "total": 8
}
