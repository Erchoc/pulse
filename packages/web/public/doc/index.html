Probes — 探针管理

GET /api/v1/probes ▶

获取探针列表，支持过滤和分页。

Query Parameters
参数类型说明
modestring可选 server | client
typestring可选 http | tcp | dns | icmp | websocket | push
enabledboolean可选 过滤启用状态
service_idstring可选 按服务 ID 过滤
pageint可选 页码，默认 1
page_sizeint可选 每页数量，默认 8

    {
      "id": "probe-1",
      "name": "Prod API Health",
      "type": "http",
      "mode": "server",

      "interval_s": 30,
      "timeout_s": 5,
      "retries": 1,
      "expect": { "status_codes": [200], "keyword": "ok" },
      "metadata": { "region": "us-east-1" },
      "enabled": true,
      "service_id": "svc-1",
      "created_at": "2026-01-15T08:00:00Z",
      "updated_at": "2026-04-10T12:30:00Z"
    }
  ],
  "total": 1
}
POST /api/v1/probes ▶

创建新探针。

Request Body
��段类型说明
namestring必填 探针名称
typestring必填 http | tcp | websocket | dns | icmp | push

Maintenance — 维护模式

POST /api/v1/services/:id/maintenance ▶

开启维护模式。维护期间探针故障不计入 SLA，告警仅通知操作人。

Path Parameters
参数类型说明
idstring必填 服务 ID
Request Body
字段类型说明
reasonstring必填 维护原因
end_atstring可选 预计结束时间（RFC3339），null = 手动结束
notify_usersstring[]可选 需通知的用户 ID 列��
Response 200 
{
  "data": {
    "service_id": "svc-1",
    "maintenance": true,
    "reason": "DB migration",
    "end_at": "2026-04-15T18:00:00Z",
    "notify_users": ["user-1"],
    "start_at": "2026-04-15T10:00:00Z"
  }
}
Error 400 
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "invalid request body"
  }
}

Webhook Payload — 推送载荷

探针状态变化时推送到配置的 Webhook URL：

{
  "event": "probe_anomaly",
  "probe_id": "probe-1",
  "probe_name": "Prod API Health",
  "service_id": "svc-1",
  "service_name": "Production API",
  "from": "up",
  "to": "down",
  "timestamp": "2026-04-14T13:22:01Z",
  "latency_ms": 5023,
  "status_code": 503,
  "message": "Health check failed: HTTP 503",
  "maintenance": false,
  "error": {
    "type": "HTTP_ERROR",
    "retry_count": 3,
    "last_error": "status 503 Service Unavailable"
  }
}
字段类型说明
eventstringprobe_anomaly | probe_recovery | maintenance_start | maintenance_end
from / tostring状态: up | down | degraded
maintenanceboolean维护中的 anomaly 仅记录不计入 SLA
